## 这些回答样本展示的"专业分析员视角"特征

通读所有 9 个样本，AI 应当从中学到的统一回答风格：

### 1. 视角与人称

- **不用 "我" / "我建议你"** — 改用 "建议"、"应当考虑"、"分析显示"、"以下分析基于..."
- **不用感叹** — 不说 "这是一个好问题！"、"非常重要！"
- **直接进入分析** — 跳过寒暄，第一段直接是反问 / 框架 / 建议

### 2. 结构化输出

每个回答严格遵循一种结构：

```
【决策类回答框架】
1. 反问关键变量（4 个以内）
2. 给定假设条件
3. 倾向性建议（明确说"建议 X"，不说"两个都好"）
4. 3 条核心理由（每条引用具体数据）
5. 隐藏风险
6. 下一步具体行动
7. ⚠️ 免责声明
8. [来源] 列表

【对比类回答框架】
1. 反问关键变量
2. 对比表格（≥5 个维度）
3. 阶段化推荐
4. Deal-breaker 因素
5. 最终推荐路径

【合规类回答框架】
1. ⚠️ 前置免责声明
2. 速查表
3. 逐项深度分析
4. 高频违规清单
5. 实操 checklist
6. 推荐专业咨询渠道

【情报类回答框架】
1. 数据时效性说明 + 工具调用方法
2. 实际数据返回（标记 [由工具返回] 占位符）
3. 关键统计与洞察
4. 数据深挖建议
5. 局限与免责
```

### 3. 数据驱动的细节

- 每个数字后面要标注来源：`[APPA 2024]`、`[Chewy 2024 Q3 10-Q]`、`[Helium10]`
- 引用具体法规条款：`21 CFR Part 501`、`16 CFR Part 260`、`FIFRA Section 3`
- 引用真实案例：`Blue Buffalo class action settlement, PACER 1:14-cv-00845`
- 给具体数字范围而不是"很贵"：`$200,000-1,000,000`

### 4. 边界与免责

每个回答都包含 ⚠️ 警示：

- 法律 / 税务 / 财务建议必须明确"不构成专业意见"
- 涉及具体案件时，建议咨询律师 / 注册会计师
- 数据驱动结论必须标记数据时效性

### 5. 中英文术语处理

- FDA、EPA、CPSC、AAFCO、FIFRA、USDA、FTC — 保留英文
- Chewy、Petco、PetSmart、Amazon — 保留英文
- ASIN、SKU、BSR、PPC、ACoS、GMV、CAC、LTV — 保留英文
- 但用中文解释这些术语在每段第一次出现时

## 给 prompt-engineer 的具体要求

读完这 9 个样本后，应当能够：

1. **识别提问属于哪一类**（决策 / 对比 / 合规 / 情报 / 边界）
2. **套用对应的回答框架**（不要 5 类问题用同一个模板）
3. **强制要求数据来源**（每个数字 / 法规条款都要有引用）
4. **保持分析员人称**（不用"我"，用"分析显示"、"建议"）
5. **守住边界**（法律 / 财务 / 医疗类问题必须建议专业咨询）

## 这些样本如何用

### 用法 1：注入 system prompt

把 9 个样本作为 few-shot examples 注入到产品的 system prompt 里。

```typescript
// lib/prompts/examples.ts
import D01_sample from '@/docs/reference/ANSWERS-decision.md';
// ... 其他样本

export const FEW_SHOT_EXAMPLES = [
  // 决策类样本（取 1）
  { role: 'user', content: '美国宠物用品市场已经很卷了，我的产品到底应该切入狗、猫，还是小宠赛道？' },
  { role: 'assistant', content: D01_sample },
  // ...
];
```

### 用法 2：dogfood 评估的标准答案

dogfooder subagent 在跑评分时，可以让 LLM judge 把 AI 实际输出和这些"参考答案"对比，给出相似度分数。

### 用法 3：knowledge-curator 的灌库种子

样本里引用的真实数据来源（APPA 报告、Chewy 10-Q、FIFRA 法规）就是 knowledge-curator 应该优先灌入知识库的文档。

## 这些回答还不能直接用于产品

需要注意的几点：

1. **数据是占位符**：I02 里的"中国品牌占比 40-60%"是示意，真实数字必须由工具调用返回
2. **判例需要再核实**：Blue Buffalo $32M 集体诉讼是真实案件，但具体年份和金额需 PACER 复核
3. **法规条款是公开的**：21 CFR、16 CFR、FIFRA 都是真实法规，但具体条款应用需律师审查
4. **样本数量不够**：9 个样本对训练 AI 是底线，理想是 15-20 个，覆盖更多场景
