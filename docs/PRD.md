# Forge Compass · 出海罗盘 — PRD v0.1

> 一个为中国宠物用品出海企业家提供决策辅助的 AI 助手。
> Forge One 孵化器的第一个 AI-native 产品 case。

---

## 0. 写在前面

这份 PRD **不是给投资人看的**，是给 Claude Code 看的。它的目的是让 Claude Code 在每一个开发回合都能回到这份文档，对齐"我们在做什么、不做什么、为什么"。

PRD 的版本号是 v0.1——这意味着它会每两周根据真实用户反馈大改一次。**任何写在这里的功能描述都是假设，不是承诺。**

## 1. 产品定位（一句话）

**给中国宠物用品出海企业家的 AI 决策助手——把 AlphaSense 级的数据深度，包装成 Claude Chat 级的极简对话。**

### 1.1 反向定义（避免做成什么）

- ❌ 不是另一个"中文 ChatGPT"
- ❌ 不是 SEO 关键词工具或竞品监控工具
- ❌ 不是亚马逊运营 SaaS（Helium10、Jungle Scout 已经做得很好）
- ❌ 不是翻译工具或本地化营销 Agent
- ❌ 不是宠物行业新闻聚合器

### 1.2 正向定义（做成什么）

- ✅ 一个"会反问、会查数据、会引用来源、会承认无知"的中文 AI 顾问
- ✅ 用户问 1 个问题，AI 给出 **结构化决策建议** 而不是百科式回答
- ✅ 每个事实都有可点击的来源链接（SEC filing、FDA 公告、Chewy 财报等）
- ✅ 当问题超出 AI 能力，主动引导到人工咨询（Forge One 网络）
- ✅ 记住用户的公司、品类、痛点，第二次对话不需要重新介绍

## 2. 用户

### 2.1 目标用户画像

**主要画像：中国宠物用品品牌创始人 / 工厂老板**

- 年龄：30-50 岁
- 公司规模：年营收 ¥5M - ¥500M
- 中文母语，英文阅读吃力但能用
- 已经在做或正在考虑做美国市场
- 销售渠道：亚马逊为主，部分尝试 TikTok Shop / Chewy / 独立站
- 痛点：信息差大、决策依据弱、没有靠谱的本地化资源、咨询费太贵

**不是目标用户**（早期不服务）：

- 大厂战略部（他们用 AlphaSense）
- 美国本地的华人创业者（信息差小）
- 投资机构（先服务企业主，后期再考虑投资场景）
- 跨境电商个人卖家（决策深度不够）

## 3. 核心用户场景（MVP 必须覆盖）

### 场景 1：决策类问题（"要不要 X"）

**例**："我现在做亚马逊宠物饮水机，要不要进 Chewy？"

**期望表现：**
1. AI 反问 3-4 个关键变量（品类、GMV、毛利、供应链）
2. 用户回答后，给出 yes/no 倾向 + 3 条核心理由 + 1 个隐藏风险
3. 引用 Chewy 最新财报 / 平台政策作为依据
4. 主动提出"要看具体数据吗"，可以拉同类目竞品销售估算

### 场景 2：对比类问题（"X vs Y"）

**例**："加州 vs 德州建仓，哪个更划算？"

**期望表现：**
1. 输出对比表格（Artifact），不是大段文字
2. 列出关键维度（税、地租、人力、运输、合规）
3. 给场景化推荐："如果你做 FBA 比例 >70%，选德州"
4. 标出 deal-breaker（如加州 Prop 65 对宠物用品的影响）

### 场景 3：合规类问题（"X 合不合规"）

**例**："我的宠物零食标签需要符合什么 FDA 规定？"

**期望表现：**
1. 引用 FDA 21 CFR 相关条款的具体段落 + 链接
2. 用中国老板能听懂的话翻译条款核心
3. 列出 3-5 个常见违规点（被退运、被下架的真实案例）
4. 主动建议："这个问题最好咨询本地 FDA 顾问，我们网络里有 X"

### 场景 4：市场情报（"X 的现状是什么"）

**例**："亚马逊宠物饮水机类目现在 Top 10 卖家是谁？"

**期望表现：**
1. 调用工具查 Amazon BSR / 评论数 / 估算销量
2. 给出 top 10 列表 + 关键数据
3. 指出趋势（"Top 5 里有 3 家是中国品牌，去年只有 1 家"）
4. 给出 1 个有价值的洞察（"价格带从 $35 上探到 $80，高端市场打开"）

### 场景 5：闲聊 / 不相关问题

**例**："你能帮我写个微博文案吗？"

**期望表现：**
礼貌拒绝并引导回核心场景。**不要试图什么都做。**

## 5. 非功能需求

### 5.1 性能

- 首字流式输出 < 2 秒
- 简单问题完整回答 < 8 秒
- 复杂问题（多次工具调用）< 30 秒
- 中文输出，地道，不要翻译腔

### 5.2 可信度（最重要）

- 每个数据型陈述必须有来源（链接或知识库引用）
- AI 不知道时必须说不知道，不能编造
- 引用必须可点击、可验证

### 5.3 上下文连续

- 单次对话内：完全连续
- 跨对话：通过 user_context 表注入用户画像
- 记忆边界：不存储用户的财务敏感数据

### 5.4 成本

- 单用户每月 LLM 成本目标 < $20
- 14 天 MVP 期间总 LLM 成本预算 < $150

## 8. 决策框架库（核心系统提示词）

这是 Wilson 的真正护城河。Claude 不能凭空做出"专业"的回答——它需要被注入决策框架。

### 8.1 框架 A：进入决策（Should I X?）

```
1. 反问关键变量（不超过 4 个）
2. 倾向：建议 / 不建议 / 视情况
3. 核心理由：3 条，每条引用具体数据
4. 隐藏风险：1 条最容易被忽视的
5. 下一步：1 个具体行动
```

### 8.2 框架 B：选择决策（X vs Y）

```
1. 输出对比表格（5-7 个维度）
2. 场景化推荐（"如果你的情况是 A，选 X；如果是 B，选 Y"）
3. Deal-breaker：标出可能直接否决的因素
4. 真实案例：1 个相关公司的真实选择和结果
```

### 8.3 框架 C：合规决策（Is X compliant?）

```
1. 引用条款原文（中英对照）
2. 中国老板视角的"白话翻译"
3. 常见违规点 + 真实案例
4. 引导到专业人士（律师/合规顾问）
```

### 8.4 框架 D：情报问题（What is X currently?）

```
1. 调用工具查实时数据
2. 给出数据本身（数字、列表、链接）
3. 给出 1 个非显而易见的洞察
4. 标记数据时间戳和不确定性
```

详细 prompt 见 `lib/prompts/system.ts`。

## 9. 成功指标（Day 14 评估）

### 9.1 定量

- 3 个种子用户，每人至少 5 次有效对话
- 平均每次对话 ≥ 3 轮
- 至少 1 个用户主动表达过"愿意付费"

### 9.2 定性（每周用户访谈）

- "我用了 AI 的回答做了一个真实决策"——至少 1 个用户达到
- "比 ChatGPT 强很多"——至少 2 个用户达到
- "我会推荐给同行"——至少 1 个用户达到

### 9.3 红旗（出现就要重新审视）

- 🚩 用户问的问题 80% 都不是 4 个核心场景 → 用户画像错了
- 🚩 AI 一半以上回答需要 Wilson 手动改 → 系统提示词不够好
- 🚩 用户用了 1-2 次就不来了 → 价值感知不够

## 10. 不变量（Invariants）

这些是写在墙上的，任何代码改动都不能违反：

1. **不编造数据**。AI 不知道时必须说不知道。
2. **不喧宾夺主**。AI 是助手，不是替用户决策的人。
3. **不收集敏感数据**。不主动问财报数字、客户名单、定价细节。
4. **不取代专业顾问**。法律、税务、医疗类问题必须建议咨询专业人士。
5. **中文 first**。界面、回答、错误提示都用中文。专业术语保留英文。
